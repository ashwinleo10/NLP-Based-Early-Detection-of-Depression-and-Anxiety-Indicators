# 🧠 NLP-Based Early Detection of Depression and Anxiety Indicators

## 📌 Overview
This project focuses on the early detection of depression and anxiety indicators using Natural Language Processing (NLP) and Deep Learning techniques. The model is built using a fine-tuned DistilBERT transformer model and includes explainability techniques such as SHAP and LIME to improve transparency and interpretability.

The system analyzes textual input and predicts whether the text contains signs of depression or anxiety, helping researchers and developers explore AI applications in mental health analytics.

---

## 🚀 Features
- Fine-tuned DistilBERT model for NLP classification
- Detection of depression and anxiety indicators from text
- Text preprocessing and tokenization pipeline
- Explainable AI using SHAP and LIME
- Performance evaluation with accuracy metrics
- Interactive prediction examples
- Jupyter Notebook implementation
